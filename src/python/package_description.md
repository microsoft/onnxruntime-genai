# ONNX Runtime GenAI

Run SLMs/LLMs and multi-modal models on-device and in the cloud with ONNX Runtime.

GenAI wheels do not bundle ONNX Runtime binaries. Install the runtime through
the wheel's ONNX Runtime package dependency. The WinML wheel uses the standard
`onnxruntime` Python package.

For more details, see: docs https://onnxruntime.ai/docs/genai and repo: https://github.com/microsoft/onnxruntime-genai
